## 3. The screenshot pipeline

### What was built

- **`site-docs/scripts/screens/capture.mjs`** — Playwright script. Reads a
  YAML shot file (`--shots`, default `scripts/screens/shots.yml`), accepts
  `--base` and `--only <id,...>`. One browser context per persona, signed
  in once through the real sign-in form (`/Login`, placeholder-driven,
  "Skip for now" for the MFA enrollment interstitial), then per shot: goto
  URL (networkidle, 30 s), optional `wait` selector, `settle` ms,
  optional `highlight` (2 px `#2563eb` outline), screenshot of `crop`
  element or full page, `animations: disabled`, `caret: hide`, written to
  `site-docs/src/assets/screens/<out>`. A `login: true` shot runs
  unauthenticated in a throwaway context. Run command (header):
  `cd site-docs && NODE_PATH=$(pwd)/../frontend/node_modules node scripts/screens/capture.mjs`.
- **`site-docs/scripts/screens/shots.yml`** — defaults (base
  `https://facet.localhost:3443`, viewport 1280×800, theme light), five
  personas (nadia, tom, lucia, ravi, admin), and seven standard shots:
  `dashboard-nadia` → `build/index-1.png`; `ticket-kanban` /
  `booking-list` / `booking-document` → `build/first-domain-1/2/3.png`;
  `item-list` → `build/first-domain-in-files-1.png`; `tom-clients-scoped`
  → `build/team-access-1.png`; `lucia-item-no-price` →
  `build/team-access-2.png`.
- **13 committed PNGs** under `site-docs/src/assets/screens/build/`.
