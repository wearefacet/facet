## 5. Discrepancies filed

- **#36 — Builder qualifies reference targets to the draft id, not the
  publish-target name.** The old tutorial (and the old live page) said the
  editor qualifies a bare target to the publish-target domain
  (`inventory.Supplier`). The editor qualifies to the draft id
  (`_06h1gc0yjgkj.Gadget`, live; `DoctypeTypeEditor.svelte:36-39`); the
  rewrite to the target name happens at publish
  (`doc/backend/draft-domains.md` §Reference-target relink; verified live:
  `wp14b-demo.Gadget` after publish).
- **#37 — View starter hint promises sharing; the editor forbids it.**
  Starter: "A new view starts personal — only you see it until you share
  it." Editor helper: "General↔personal cannot be changed after creation."
  A personal view cannot be shared later; the hint overstates.
