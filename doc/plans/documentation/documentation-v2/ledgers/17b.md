(2), `agents/` (3). All pages rewritten in place and verified against
`eee55a2`. Batch A paths (`build/apps/index.md`, `how-apps-work.md`,
`quickstart.md`, `connect/*`) belong to another agent — untouched. Batch A
pages still carry old front-matter (`verified_at: a77c6171`); expected, and
left alone.

Every live call ran against the shared dev instance
(`https://facet.localhost:3443`, socket dial `ws://127.0.0.1:3000/Ws`) with
the Brightwater Rentals data loaded. No restart, no `db_reset`. Throwaway
records created and deleted during the checks: 2 WS probe companies, 1 REST
probe company (create → delete → restore → delete), 1 import probe row, 1
artifact upload (force-deleted via the admin route), 1 assistant probe
conversation (archived), 1 SDK probe app + API key (app deleted). Nothing
left behind. Cookie sessions used `X-Requested-With: XMLHttpRequest`
everywhere; bracket filters used `curl -g`.
