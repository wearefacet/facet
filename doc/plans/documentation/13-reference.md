## Generator mechanics (all generated pages)

- Scripts live in `scripts/gen_docs/` (repo root), one per reference, plus a `make gen-docs` target that runs all of them.
- Output: overwrite the target `.md` in `site-docs/src/content/docs/reference/`, keeping front-matter but refreshing `verified_at`.
- A header comment in each script states its source of truth. Never hand-edit a generated page; fix the generator.
- CI: the release workflow runs `make gen-docs` before the site build. Wiring that line is an integration note for the release pipeline owner — record it in `doc/site-docs.md`, do not edit CI files in this WP.

`reference/index.md` (from WP 01): the part that runs last finishes the index.
