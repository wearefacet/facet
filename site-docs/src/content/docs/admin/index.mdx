This tab is for the administrator and the operator — often the same person in
a small organization. It covers the whole run book: install Facet, configure
it, decide who sees and does what, follow every change, and keep the
installation healthy. Each page stands alone; the cross-links fill in the
model.

Evaluating Facet first? [Security and governance](/discover/security/)
answers the same questions from an auditor's point of view.
