Le tableau de bord est la page que Facet ouvre après la connexion. Il vous
salue, montre votre rôle actif et vous donne des cartes pour rejoindre
chaque domaine que vous pouvez lire. Chaque domaine a son propre tableau de
bord, avec vos vues épinglées et vos enregistrements récemment ouverts.
Commencez ici votre travail quotidien.

## Avant de commencer

- **Un compte.** Il vous faut un compte Facet. Voir
  [Connexion, MFA et mot de passe](/fr/use/first-day/sign-in/).
- **Les bonnes cartes.** Votre rôle décide des cartes que vous voyez. Un
  domaine hors de vos droits ne s’affiche pas. Voir
  [Rôles : qui voit et fait quoi](/fr/discover/how-it-works/roles/).

## La page d’accueil

Ouvrez l’adresse de votre instance et connectez-vous. La page d’accueil
montre, de haut en bas :

![Nadia's home page with the greeting, the key surfaces, and the domain cards.](/screens/use/first-day-tour-1.png)

| Partie | Ce qu’elle montre |
| --- | --- |
| Salutation | Votre prénom, et le rôle sous lequel vous travaillez, par exemple *Manager*. |
| Surfaces clés | Des liens vers les zones que votre rôle autorise, comme **Builder**. Un lien que votre rôle n’autorise pas reste caché. |
| Applications | Une carte par application que votre organisation fait tourner ; la section se cache quand il n’y en a pas. Une carte que votre rôle ne peut pas ouvrir affiche une mention de verrou. |
| Brouillons en cours | Les brouillons de domaines sur lesquels vous ou votre équipe travaillez, avec une coche quand ils sont prêts à publier. |
| Domaines | Une carte par domaine que vous pouvez lire, par exemple *Equipment* ou *Rentals*. |

Sélectionnez une carte de domaine pour ouvrir son tableau de bord.

:::note
Quand votre rôle peut créer des types d’enregistrement, la section Domaines
affiche un petit bouton plus sur chaque carte de domaine. Il ouvre la boîte
de dialogue de création de type d’enregistrement. Le brouillon et les
réglages de domaine se font dans le Builder ; voir
[Construire des domaines](/fr/build/).
:::

Quand votre compte ne peut lire aucun domaine, la section Domaines affiche
à la place une carte de premier démarrage : *"Aucun domaine disponible"*, avec
une note pour contacter votre administrateur.

## Le tableau de bord du domaine

Le tableau de bord du domaine montre un seul domaine : ses types
d’enregistrement, les vues que vous avez épinglées et les enregistrements
que vous avez ouverts en dernier.

![Nadia's Rentals domain dashboard: the header with counts, the pinned views, the recently viewed chips, and the record-type list.](/screens/use/first-day-dashboard-1.png)

| Section | Ce qu’elle montre |
| --- | --- |
| En-tête | Le nom du domaine, et les décomptes de ses types d’enregistrement et de ses enregistrements. |
| Vues épinglées | Une carte par vue que vous avez épinglée, avec le type de vue (tableau, kanban ou calendrier) et le décompte d’enregistrements. Sélectionnez une carte pour ouvrir la liste. |
| Consultés récemment | Des puces pour les enregistrements que vous avez ouverts en dernier dans ce domaine, du plus récent au plus ancien. |
| Types d’enregistrement | Chaque type avec son décompte d’enregistrements, et des liens vers ses vues enregistrées. |

:::tip
Épinglez les vues que vous utilisez chaque jour. Ouvrez une vue sur une page
de liste et sélectionnez la commande d’épinglage à côté des onglets. La vue
apparaît alors sur ce tableau de bord. Voir
[Listes, filtres et vues enregistrées](/fr/use/finding/lists-and-views/).
:::

## Étapes

### 1. Ouvrez votre liste quotidienne

Connectez-vous, sélectionnez une carte de domaine, puis une vue épinglée.
La liste s’ouvre avec cette vue active. C’est le chemin le plus court vers
votre travail quotidien.

### 2. Revenez à un enregistrement déjà travaillé

Ouvrez le tableau de bord du domaine et sélectionnez une puce sous
**Consultés récemment**. L’enregistrement s’ouvre. Chaque puce montre le nom
de l’enregistrement et l’ancienneté de votre dernière ouverture, par exemple
`10m` ou `yest`.

### 3. Trouvez un type d’enregistrement

Ouvrez le tableau de bord du domaine et lisez la liste des types
d’enregistrement. Elle montre chaque type avec son décompte
d’enregistrements. Un type de plus de 1000 enregistrements affiche `1000+`.

1. Sélectionnez le nom du type pour ouvrir sa liste.
2. Ou sélectionnez une vue enregistrée en dessous.

Au-delà de six types d’enregistrement, la liste montre les six premiers et
un bouton **Afficher N de plus**. Sélectionnez-le pour voir le reste.

## Exemple

Un chemin quotidien dans le domaine de locations Brightwater :

```
/                      sélectionnez la carte Rentals
/rentals               sélectionnez le type Booking, ou sa vue Calendrier
/rentals/Booking       la liste des réservations s’ouvre — le travail du jour commence ici
```

## Dépannage

### Une carte de domaine manque

Votre rôle ne lit pas ce domaine. Demandez à votre administrateur. Un
brouillon sur lequel un collègue travaille encore reste dehors aussi ; un
domaine publié s’affiche toujours.

### La section Vues épinglées est vide

Vous n’avez encore épinglé aucune vue. La section dit : *"Épinglez une vue
et elle apparaîtra ici."*

1. Ouvrez une liste.
2. Sélectionnez une vue.
3. Sélectionnez la commande d’épinglage.

### La section Consultés récemment est vide

Vous n’avez encore ouvert aucun enregistrement dans ce domaine, ou votre
navigateur a effacé son stockage. La section dit : *"Les documents que vous
ouvrez apparaîtront ici."*

### Un décompte affiche un tiret au lieu d’un nombre

Le décompte n’est pas encore chargé, ou votre rôle ne peut pas compter ce
type d’enregistrement. Le décompte se remplit quand les données arrivent.
