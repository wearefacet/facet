<SectionHead eyebrow="Ce que Facet porte" title="Un seul foyer gouverné pour vos données métier">

Facet est une plateforme applicative gouvernée pour les organisations de
petite et moyenne taille. Vous modélisez vos données métier dans des domaines.
Chaque application — écrite par votre équipe ou par un agent IA — lit et écrit
ces données sous les mêmes droits contrôlés, avec la trace complète de chaque
modification.

</SectionHead>

<LandingGrid>
	<Pillar kind="data" title="Données">
		Modélisez l’activité en domaines — clients, équipements, recrutement —
		une tranche à la fois. Documents et fichiers vivent dans Facet, pas dans
		chaque application.
	</Pillar>
	<Pillar kind="permissions" title="Droits">
		Les rôles décident qui lit et qui écrit, jusqu’au champ et à la ligne. La
		couche de données les applique : aucune application ne contourne les règles.
	</Pillar>
	<Pillar kind="history" title="Historique">
		Chaque modification entre dans un journal en ajout seul : qui a changé
		quoi, quand et pourquoi. Revenez sur n’importe quel document à un état
		antérieur.
	</Pillar>
</LandingGrid>

<SectionHead eyebrow="Comment ça s’articule" title="Toutes les applications passent par la même porte">

Une application ne touche jamais la base de données. Elle se connecte en OAuth
et appelle l’API avec les droits que vous lui avez donnés. Supprimez
l’application : les données, les règles et l’historique restent.

</SectionHead>
