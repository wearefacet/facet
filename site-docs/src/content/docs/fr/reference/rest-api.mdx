Utilisez cette page pour consulter une route : ses méthodes, ses
paramètres et ses codes de statut.

Cette page intègre la référence interactive de l’API REST des routes de
documents, d’audit et d’IAM. Le site embarque une copie de
`doc/api/openapi.json`, servie à l’adresse `/api/openapi.json`.
`make gen-docs-rest-api` actualise cette copie.

Les guides pratiques sous `/apps/` présentent les mêmes routes avec des
exemples concrets.

:::note
Le fichier OpenAPI couvre un sous-ensemble de la surface REST (la
fonctionnalité `PLT-12`) ; cette référence est donc partielle. Le fichier
dessert ces groupes de routes :

- CRUD des documents : lister, créer, lire, mettre à jour et supprimer les
  documents d’un doctype
- historique des documents, retour arrière et restauration, y compris les
  documents enfants
- liens entrants : les documents qui référencent un document
- le journal d’audit global et sa route de retour arrière
- les routes de comptes IAM : profil du compte courant, états des
  identifiants, mot de passe temporaire et invitation

Tous les autres groupes de routes — webhooks, fichiers, secrets, recherche,
WebSocket et authentification — sont documentés dans les pages rédigées à

la main sous `/apps/`.
:::
