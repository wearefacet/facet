Cet onglet rassemble les détails exacts : routes, commandes, clés, types de
champs, opérateurs, schémas et payloads. Il répond à « quel est le détail
exact ? », pas à « comment faire ? ». Quand c’est possible, les pages sont
générées depuis le code source et restent donc justes sans retouche manuelle —
ne modifiez jamais une page générée à la main ; lancez sa cible
`make gen-docs-<name>`.

Vous lisez en tant qu’agent ? Commencez par `/llms.txt`, ou récupérez
n’importe quelle page en markdown brut à l’adresse `<page path>.md`.
