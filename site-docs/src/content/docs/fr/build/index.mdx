Cet onglet réunit deux types de bâtisseurs. **L’auteur** modélise le métier :
types d’enregistrements, champs, vues et règles, construits dans l’app ou en
fichiers. **Le développeur** construit les apps qui utilisent ces données :
apps navigateur, services backend et agents IA. Les tutoriels ci-dessous vous
mènent l’un et l’autre d’un serveur vide à un domaine fonctionnel et à une app
livrée.

Si vous hésitez encore sur Facet, commencez plutôt par
[Architecture en un coup d’œil](/fr/discover/how-it-works/).
