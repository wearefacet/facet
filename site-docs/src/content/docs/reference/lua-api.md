Lua scripts run in a sandbox with a fixed set of globals. Lifecycle hooks, named actions, and domain hooks get the full surface: `document`, `notification`, `util`, `date`, and `math.clamp`. Computed fields get `util` and `date` plus a read-only `document` table. They get no `notification` and no query-backed `util` gates. Scripts also receive the `ctx` object and an `error(msg)` collector; see lifecycle scripts and guards.

## document

Reads accept a qualified `domain.Doctype` first argument. A foreign read needs an active domain grant; the returned content is reduced to the covered fields.

| Function | Signature | Purpose |
| --- | --- | --- |
| `document.create` | `doc_type, content_json` | Creates a new document of the given doctype in the same domain. |
| `document.get` | `doc_type, doc_id` | Fetches a document by doctype and ID. |
| `document.update` | `doc_type, doc_id, content_json` | Partially updates a document. |
| `document.delete` | `doc_type, doc_id` | Soft-deletes a document. |
| `document.list` | `doc_type, [filters], [sort], [page], [per_page]` | Lists documents of the given doctype. |

:::note
Every `document.*` function raises a catchable Lua error on failure. Handle it with `pcall`.
:::

## date

| Function | Signature | Purpose |
| --- | --- | --- |
| `date.add` | `iso, n, unit` | Adds `n` units; negative `n` subtracts. |
