Use this page to look up a route: its methods, parameters, and status codes.

This page embeds the interactive REST API reference for the document, audit, and IAM routes.
The site vendors a copy of `doc/api/openapi.json` at `/api/openapi.json`.
`make gen-docs-rest-api` refreshes the copy.

The how-to pages under `/build/apps/` teach the same routes with worked examples.

:::note
The OpenAPI file covers a subset of the REST surface (feature `PLT-12`), so this reference is partial.
The file serves these route groups:

- document CRUD: list, create, read, update, and delete documents of one doctype
- document history, rollback, and restore, including child documents
- backlinks: the documents that reference one document
- the global audit log and its rollback route
- the IAM account routes: current account profile, credential states, temporary password, and invite

Every other route group — webhooks, files, secrets, search, WebSocket, and authentication —
is documented on the hand-written pages under `/build/apps/`.
:::
