Use this page to find a `facet` command and check how it handles options.

One `facet` call can run several commands in a row: `facet db_reset --yes seed:dev`.
A command that consumes its own options reads every following token as its option.
Such a command must be last in a chain.
Every other command takes only its dash options, and the chain continues after them.
`server` is the default command and starts the HTTP server.
