> Generated from `src/settings/keys.cr` by `make gen-docs-account-settings`. Do not edit this file by hand.

Use this page to find the key, its type, and its default. Account settings are
per-account preferences. The service stores them as `(app, key)` pairs and
refuses any pair this registry does not list.

The table lists every registered key, its type, and its default.

| Key | Type | Default | Purpose |
|---|---|---|---|
| `core.language` | string | "en" | Language code for the account's interface. Allowed values: en, fr. |
| `core.pinned_collection_views` | array | [] | Collection views the account pins in doctype listings. |
| `core.pinned_doctypes` | array | [] | Qualified doctype names the account pins to the top of the sidebar. |
| `core.show_welcome` | bool | true | Replays the first-run welcome tour when true; the tour writes false when dismissed. |
| `core.timezone` | string | "auto" | IANA timezone the account's dates and times render in. |
| `notifications.in_app` | bool | true | Gates the client-side notification delivery: bell, badge, and live subscription. |

Two keys carry a server tier before their registry default. An account with no
value of its own follows the instance's system settings:

- `core.language` follows `localization.default_language`.
- `core.timezone` follows `localization.default_timezone`.
