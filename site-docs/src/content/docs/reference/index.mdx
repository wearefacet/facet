This tab holds the exact details: routes, commands, keys, field types,
operators, schemas, and payloads. It answers "what is the exact…?", not "how
do I…?". Pages are generated from the source where possible, so they stay
true without hand edits — never edit a generated page by hand; run its
`make gen-docs-<name>` target.

Reading as an agent? Start at `/llms.txt`, or fetch any page as raw markdown
at `<page path>.md`.
